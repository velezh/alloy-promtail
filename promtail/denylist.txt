# Packages that must not be linked into alloy-promtail.
#
#   <pattern> [unless <group>...]
#
# "=path" matches path only, "path/" matches packages below path, "path" matches
# path and packages below it. Rules with "unless" apply only when none of the
# listed component groups (COMPONENT_GROUPS) is enabled.
#
# A violation after an upstream sync means upstream started importing the
# package from code linked into alloy-promtail: `make -C promtail deps` prints
# the import chain; cut it with an overlay entry or drop the component.
